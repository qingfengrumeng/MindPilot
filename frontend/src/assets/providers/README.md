# Provider icons

DeepSeek, Kimi, Qwen, Doubao and Zhipu icons are bundled from [LobeHub Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons) under the accompanying MIT license. They render locally without contacting a CDN.

Preset language API references:
- [DeepSeek model listing](https://api-docs.deepseek.com/api/list-models/)
- [Kimi API quick start](https://platform.kimi.com/docs/get-api-key)
- [Qwen API endpoints](https://help.aliyun.com/zh/model-studio/web-search)

Non-language model defaults match the adapters currently implemented by this project. Model names remain editable; presets do not imply a user's account has access.
